# 🎣 Task 2 — Phishing Awareness Training Module

An educational web module about phishing attacks — part of the **CodSoft Cyber Security Internship**.

## 🎯 Purpose

Teach everyday users how to identify and avoid phishing attacks through clear examples, a real-world case study, and an interactive quiz.

## 📌 What's Inside

- **What is Phishing?** — definition + 6 common types
- **6 Red Flags** — visual cards showing what to look for
- **Real Case Study** — Google & Facebook $100M scam (2013–2015)
- **9 Practical Safety Tips** — actionable advice
- **Interactive Quiz** — 5 questions with instant scoring

## 🚀 How to Run

Just open `index.html` in any modern browser.

No server, no dependencies — pure HTML, CSS, JavaScript.
